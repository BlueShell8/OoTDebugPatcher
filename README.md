# OoTDebugPatcher
A patcher to convert the OoT file into the Debug version.

# Usage

Open the EXE file, select the original Zelda OoT file, and the tool will convert it into the Debug version. The output file will be named **ZELOOTD.z64**.

# How It Works

The tool utilizes a BPS file that has been converted into a text file using Base64 encoding. The contents of this text file are embedded directly within the code and are used by the tool to transform the OoT ROM into the Debug file.
